# @vadd/cli

`@vadd/cli` is the installable package for VADD, a localhost comprehension and verification
layer that wraps Claude Code over ACP.

## Usage

```sh
npx @vadd/cli
```

This starts a local server and opens it in your browser. See the
[main VADD README](../../README.md) for prerequisites, first-run instructions, and the
project's privacy guarantees.
